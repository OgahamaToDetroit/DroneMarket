# สำรวจตลาดโดรนไทย

โปรเจกต์วิเคราะห์ข้อมูลตลาดโดรนในประเทศไทยจาก**ข้อมูลเปิดของหน่วยงานรัฐ** —
ตอบว่าตลาดใหญ่แค่ไหน โตแค่ไหน ใครครองตลาด และคนไทยใช้โดรนทำอะไร

ทุกตัวเลขในรายงานตรวจสอบย้อนกลับได้ถึงแหล่งข้อมูลต้นทาง และสคริปต์ทุกตัวรันซ้ำได้

---

## เริ่มใช้งาน

```bash
pip install -r requirements.txt
```

ข้อมูลส่วนใหญ่**ไม่ต้องใช้ API key** ยกเว้น UN Comtrade — ถ้าจะใช้ ให้คัดลอก
`.env.example` เป็น `.env` แล้วใส่ key ที่สมัครฟรีจาก https://comtradedeveloper.un.org/

```bash
cp .env.example .env      # แล้วแก้ COMTRADE_API_KEY ในไฟล์
```

`.env` ถูก gitignore ไว้แล้ว key จะไม่หลุดขึ้น git

> **ข้อมูลดิบไม่ได้อยู่ใน git** (`data/raw/*.xlsx`, `*.json` ถูก ignore)
> เพราะดาวน์โหลดใหม่ได้ — ดูลิงก์ใน [`SOURCES.md`](SOURCES.md)

---

## โครงสร้างโฟลเดอร์

```
data/raw/         ข้อมูลดิบที่ดาวน์โหลดมา (ไม่อยู่ใน git)
data/processed/   ผลประมวลผลเป็น CSV/JSON (อยู่ใน git — ใช้สร้างรายงานได้เลย)
scripts/          สคริปต์ดึงและวิเคราะห์ข้อมูล
reports/          รายงานแต่ละรอบ แยกโฟลเดอร์ตามวันที่
DATA.md           สรุปภาษาชาวบ้านว่ามีข้อมูลอะไรบ้าง ตอบอะไรได้/ไม่ได้  ← เริ่มที่นี่
SOURCES.md        แหล่งข้อมูลทั้งหมด + สเปก API + กับดักที่เจอจริงตอนใช้งาน
```

> **อ่านครั้งแรกให้เริ่มที่ [`DATA.md`](DATA.md)** — เขียนแบบไม่ใช้ศัพท์เทคนิค
> ว่าตอนนี้มีข้อมูลอะไรอยู่ในมือบ้างและตอบคำถามอะไรได้บ้าง

## สคริปต์

รันจาก **root ของโปรเจกต์** เสมอ (เช่น `python scripts/overview.py`)
ไม่ใช่จากในโฟลเดอร์ `scripts/`

### กสทช. — ทะเบียนโดรน (จำนวนเครื่อง แบรนด์ จังหวัด)

| สคริปต์ | ทำอะไร | ผลลัพธ์ |
|---|---|---|
| `explore.py` | สำรวจโครงสร้างไฟล์ดิบ ดูคอลัมน์และค่าที่หายไป | `scripts/explore_out.txt` |
| `overview.py` | ภาพรวมตลาด — รายปี แบรนด์ จังหวัด วัตถุประสงค์ | `data/processed/summary_by_*.csv` |
| `purpose_buckets.py` | จัดกลุ่มคอลัมน์วัตถุประสงค์ที่มีหลายค่าปนกัน | `data/processed/purpose_buckets.json` |

### กรมศุลกากร — การค้าแยกพิกัด 8/11 หลัก (ไม่ต้องใช้ key) ⭐

| สคริปต์ | ทำอะไร | ผลลัพธ์ |
|---|---|---|
| `customs_hs_trade.py` | นำเข้า/ส่งออก HS 8806 **แยกพิกัด 8 หลัก = แยกชั้นน้ำหนัก** + แยกประเทศครบทุกราย | `data/processed/customs_hs8806_*.csv` |

```bash
python scripts/customs_hs_trade.py                              # ปีปฏิทิน 2565-2569
python scripts/customs_hs_trade.py --years 2568 --skip-country  # เร็ว ไม่โหลดไฟล์ 118 MB
python scripts/customs_hs_trade.py --hs 8802 --years 2563,2564  # โดรนก่อนมี HS 8806
```

ได้ 3 ไฟล์: `_by_code` (รายพิกัด) · `_by_country` (พิกัด × ประเทศ) ·
`_balance` (ตารางเทียบเข้า-ออก + ผล GATE)

> **นำเข้าเป็น CIF ส่งออกเป็น FOB** — เอา "นำเข้า − ส่งออก" ตรง ๆ จะได้ค่าระวางมาปน
> สคริปต์จึงมี **GATE** คัดว่าพิกัดไหนวัดอุปสงค์ในประเทศได้จริง (ต้องบวกทั้งมูลค่าและ
> จำนวนชิ้น และส่วนต่าง > 10% ของขานำเข้า) พิกัดที่ไม่ผ่านให้เขียนว่า "วัดไม่ได้"

### กระทรวงพาณิชย์ — ศุลกากรและทะเบียนบริษัท (ไม่ต้องใช้ key)

| สคริปต์ | ทำอะไร | ผลลัพธ์ |
|---|---|---|
| `moc_hs_trade.py` | มูลค่านำเข้า/ส่งออก HS 8806 **รายเดือน** ทั้ง USD และบาท | `data/processed/moc_hs8806_monthly.csv` |
| `moc_importers.py` | ค้นบริษัทที่ชื่อเกี่ยวกับโดรนในทะเบียนผู้นำเข้า-ส่งออก | `data/processed/moc_drone_companies.csv` |

```bash
python scripts/moc_hs_trade.py --years 2022,2023,2024,2025
python scripts/moc_hs_trade.py --hs 880610 --years 2025      # เจาะรหัสย่อย
```

> ข้อมูลชุดเดียวกับกรมศุลกากร แต่ให้ USD ด้วยและตัดเหลือ **top 10 ประเทศ/เดือน**
> ถ้าต้องการประเทศครบให้ใช้ `customs_hs_trade.py` แทน

### e-GP — จัดซื้อจัดจ้างภาครัฐ (ไม่ต้องใช้ key)

| สคริปต์ | ทำอะไร | ผลลัพธ์ |
|---|---|---|
| `egp_drone_procurement.py` | โครงการจัดซื้อโดรนของหน่วยงานรัฐ — **ราคาจริง + ชื่อผู้ขาย + จังหวัด** | `data/processed/egp_drone_projects.csv` |

```bash
python scripts/egp_drone_procurement.py                        # ปีงบ 2565-2568
python scripts/egp_drone_procurement.py --from-cache           # วิเคราะห์ซ้ำจาก CSV เดิม
python scripts/egp_drone_procurement.py --years 2568 --max-mb 60   # ทดสอบเร็ว
```

> สตรีมไฟล์ CSV ~19.6 GB จาก data.go.th แล้วกรองทิ้งเลย ไม่เก็บลงดิสก์ (ใช้เวลา ~30-40 นาที)
> **ถ้าจะแก้แค่ส่วนวิเคราะห์ ให้ใช้ `--from-cache`** จะได้ไม่ต้องโหลดใหม่
> โหมด `--max-mb` เขียนลงไฟล์ `_partial.csv` คนละไฟล์ จะได้ไม่ทับผลจริงโดยไม่ตั้งใจ

### UN Comtrade — มูลค่าการค้ารายปี (ต้องมี API key)

| สคริปต์ | ทำอะไร | ผลลัพธ์ |
|---|---|---|
| `comtrade_fetch.py` | ดึงมูลค่าการค้า HS 8806 รายปี | `data/processed/comtrade_hs8806_*.csv` |
| `comtrade_analyze.py` | วิเคราะห์ + เชื่อมกับข้อมูล กสทช. | `scripts/comtrade_analyze_out.txt` |
| `comtrade_deepdive.py` | ราคาต่อลำ ช่องว่างการจดทะเบียน ทดสอบ re-export | `scripts/comtrade_deepdive_out.txt` |
| `comtrade_mirror_check.py` | ตรวจตัวเลขส่งออกจากฝั่งประเทศปลายทาง | `scripts/comtrade_mirror_out.txt` |

> `comtrade_mirror_check.py` import ฟังก์ชันจาก `comtrade_fetch.py`
> **อย่าย้ายหรือเปลี่ยนชื่อสองไฟล์นี้** โดยไม่แก้ import

### วิเคราะห์เจาะบริษัท

| สคริปต์ | ทำอะไร | ผลลัพธ์ |
|---|---|---|
| `ics_market_position.py` | ตำแหน่งของ iCreativeSystems (ICS) — ทะเบียน กสทช. · สัญญาภาครัฐ · คู่แข่ง · ตลาดอีสาน | `scripts/ics_market_position_out.txt` |

> ต้องรัน `egp_drone_procurement.py` ให้มี CSV ก่อน และต้องมี `data/raw/drone_data.xlsx`

### สร้างรายงาน

| สคริปต์ | ทำอะไร | ผลลัพธ์ |
|---|---|---|
| `build_charts_update03.py` | สร้าง HTML ของกราฟจาก CSV แล้วแทรกลงรายงานที่มี marker `<!--CHART_A-->` | `data/processed/update03_chart_*` · `scripts/build_charts_update03_out.txt` |

รันซ้ำได้เรื่อย ๆ — ตัวเลขในกราฟจึงมาจากข้อมูลจริงเสมอ ไม่ใช่พิมพ์มือ
และไฟล์ `_out.txt` เก็บตัวเลขทุกตัวที่รายงานอ้างถึง (correlation, ราคาต่อลำ, จุดเปลี่ยน)

> **มี guard กันรายงานเพี้ยน** — ถ้า CSV ไม่ครบปีที่รายงานอ้างถึง สคริปต์จะไม่แทรกกราฟ
> แล้วบอกให้ไปดึงข้อมูลให้ครบก่อน เพราะถ้าแทรกกราฟ 2 ปีลงในรายงานที่ตารางเป็น 4 ปี
> รายงานจะขัดแย้งกันเองแบบไม่มีอะไรเตือน

## รายงาน

ดัชนีรายงานทั้งหมดอยู่ที่ [`reports/UPDATES.md`](reports/UPDATES.md) เรียงล่าสุดก่อน

รายงานแยกเป็น 2 ชั้น:
- **ฉบับภายใน** — มีเรื่องคุณภาพข้อมูล ข้อจำกัด และกับดักที่เจอ
- **ฉบับสาธารณะ** (`public-summary.html` + PDF) — ฉบับที่ส่งให้คนอื่นอ่านได้

> ฉบับสาธารณะที่ใช้จริงมีเพียงฉบับเดียว ณ เวลาหนึ่ง — ฉบับเก่าจะถูกทำเครื่องหมายว่า
> "เก็บไว้เป็นประวัติ" ใน `UPDATES.md` ดูที่นั่นก่อนเสมอว่าฉบับไหนคือฉบับปัจจุบัน

**วิธีเพิ่มรายงานรอบใหม่**
1. สร้างโฟลเดอร์ `reports/YYYY-MM-DD_update-NN/`
2. เขียนรายงาน HTML (ยกโครง `<style>` จากรอบก่อนมาใช้ได้เลย — กราฟเป็น CSS ล้วน ไม่พึ่ง library)
3. สร้าง PDF: `chrome --headless --no-pdf-header-footer --print-to-pdf=out.pdf file:///path/to.html`
4. เพิ่มรายการใหม่ไว้**บนสุด**ของ `reports/UPDATES.md`

## หลักการทำงานของโปรเจกต์นี้

1. **ตัวเลขต้องตรวจย้อนกลับได้** — ทุกตัวเลขในรายงานมาจากสคริปต์ที่รันซ้ำได้ ไม่พิมพ์มือ
2. **บันทึกกับดักไว้ด้วย** — `SOURCES.md` เก็บทั้งวิธีใช้ API และจุดที่เคยพลาดจริง
   เช่น พารามิเตอร์ที่ชื่อไม่ตรงกับที่คาด หรือค่า default ที่ทำให้ข้อมูลนับซ้ำ
3. **แยกสิ่งที่ยืนยันแล้วออกจากสิ่งที่อนุมาน** — ถ้ายังพิสูจน์ไม่ได้ ต้องเขียนกำกับไว้
4. **ถ้าข้อสรุปเก่าผิด ให้แก้และบันทึกว่าแก้อะไร** ไม่ลบทิ้งเงียบ ๆ
   (ดูตัวอย่างที่ Update 03 แก้ข้อสรุปของ Update 02)

| แหล่ง | ได้อะไร | key |
|---|---|---|
| กสทช. Data Catalog | ทะเบียนโดรน 205,287 รายการ แยกแบรนด์/รุ่น/จังหวัด/วัตถุประสงค์ | ไม่ต้อง |

| DBD DataWarehouse | งบการเงินรายบริษัท — ติด WAF ทำ pipeline ไม่ได้ ต้องเปิดดูเอง | — |

⚠️ **ศุลกากร · พาณิชย์ · Comtrade เป็นข้อมูลก้อนเดียวกัน** (ตรงกันทุกบาท) ห้ามใช้ยืนยันกันเอง
